# Чек-лист сдачи

Сдача и изменение доступа к репозиторию выполняются командой отдельно.
Этот файл не подтверждает выполнение пунктов или отправку решения.

## Воспроизводимость

- [ ] На чистом окружении проверены команды установки, запуска и тестов README.
- [ ] Без backend и ключей приложение работает с честным пустым состоянием.
- [ ] Demo выключен по умолчанию; синтетика не проходит итоговый экспорт.
- [ ] Выполнена визуальная приёмка из [DEMO.md](DEMO.md).
- [ ] Воспроизведён реальный end-to-end прогноз по архивной погоде.
- [ ] Реальный smoke-test пройден отдельно от fixture-тестов.
- [ ] README содержит реальные пути данных/моделей, зону, нормировку и конфигурацию.
- [ ] Смена вкладок/экспорт не повторяют внешние вызовы или обучение.

## Данные и прогноз

- [ ] Реальные `site_id`, координаты и часовой пояс обеих турбин подтверждены.
- [ ] Training cutoff не включает проверочные целевые значения.
- [ ] Архивная прогнозная погода доступна к каждому историческому выпуску.
- [ ] Январские MAE/RMSE и baseline рассчитаны на независимых сравнимых примерах.
- [ ] Фактическая выработка и ошибки февраля не выдуманы.
- [ ] Replay отмечает ошибки и сохраняет разные версии одного исторического выпуска.
- [ ] Полнота проверяется по `(site_id, target_time)`, не одним числом строк.
- [ ] Февральская сетка содержит 28×24×2 = 1344 точки при согласованной зоне
      с 24 часами в каждых сутках; неверные/повторные часы не заменяют пропуски.
- [ ] 48-часовые выпуски конца февраля сохраняют мартовские часы.
- [ ] Правило выбора выпуска на час согласовано и не использует будущие выпуски.
- [ ] Перед экспортом повторно проверены поля, сетка, время, NaN/inf, диапазон,
      дубли, квантили, происхождение и историческая допустимость модели.
- [ ] Формат submission уточнён; внутренний CSV не назван официальным.

## Репозиторий и передача

- [ ] Проверены `git diff`, staged diff и список включённых файлов.
- [ ] В публикации нет `.env`, ключей, токенов, исходных CSV и закрытых кэшей.
- [ ] Пакет воспроизводимости составлен по списку разрешённых файлов, не ZIP репозитория.
- [ ] Права и публичность репозитория соответствуют разрешению команды.
- [ ] Вклады участников указаны по фактической работе, backend не приписан UI.
- [ ] Итоговая версия/commit и ссылка сверены после разрешённой публикации.
- [ ] На платформе отдельно нажата **«Сдать решение»**, получено подтверждение.

Backend, реальные данные/модели, backtest и реальный погодный smoke-test сейчас
отсутствуют. UI-тесты не закрывают эти пункты.
