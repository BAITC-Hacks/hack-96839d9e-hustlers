# Чек-лист готовности и сдачи

Статус после локальной приёмки 23.09.2026. Отметки относятся к указанным
проверкам, а не к отправке решения на платформу. Сценарий показа — [DEMO.md](DEMO.md).

## Реальные данные и ML

- [x] Обе SCADA-копии, архив оригинальных NOAA GFS и веса моделей доступны.
- [x] Backend использует площадки `turbine_1` / `turbine_2`, координаты из
      конфигурации проекта и `Asia/Almaty`; внутри хранится UTC.
- [x] Погода проверяется на доступность к историческому моменту; будущие
      наблюдения не подставляются вместо прогноза.
- [x] Январские проверочные модели отделены от финальных; cutoff проверяется.
- [x] Январские MAE/RMSE и baseline пересчитаны по одинаковым парам.
- [x] Прогноз обеих турбин на 24/48 часов проверен с настоящими моделями.
- [x] Февральский replay: 58 выпусков, полные выпуски включают март.
- [x] Таблица февраля: 1 344 уникальных часа двух турбин, точная временная сетка.
- [x] Обновление создаёт связанную версию, сохраняет старую и не переобучает ML.
- [x] Повтор одинакового расчёта не создаёт дублирующей публикации.
- [x] Отсутствие февральского факта явно указано; февральские метрики не заявляются.
- [ ] Организаторы подтвердили предположения о начале SCADA-интервала и нулевой
      задержке поступления. Пока это документированные настройки модели.
- [ ] Уточнён официальный формат сдачи. Нынешние CSV — формат команды.

## Интерфейс и воспроизводимость

- [x] Полная локальная проверка: 162 теста без пропусков, включая настоящий bundle,
      погодный кэш, ML, replay и BackendAdapter.
- [x] В Chromium проверены реальные прогнозы, январский отчёт, обновление,
      replay и выгрузка всех 1 344 февральских часов; JavaScript-ошибок нет.
- [x] Синтетика выключена по умолчанию и не проходит итоговый экспорт.
- [x] Произвольный загруженный JSON не получает доверие автоматически.
- [x] README содержит пути моделей/данных, нормировку и команды запуска.
- [x] Просмотр результатов не запускает обучение; повторные UI-вызовы проверены.
- [ ] Установка на отдельном чистом компьютере команды повторена целиком.

## Живой AI-агент

- [x] Реализован Responses API-цикл со строгими схемами и проверками backend.
- [x] Ошибки, ограничения инструментов и резервный режим покрыты тестами с
      тестовым OpenAI-клиентом.
- [x] Для отдельного запуска команда настроила ключ и модель локально.
- [x] Проверен сохранённый результат запуска через Responses API: одна турбина,
      48 часов, шесть успешных инструментов, исполнитель `openai_responses`.
      Основание и границы проверки — [отчёт](../data/reports/llm_smoke_verification.json).
- [ ] Живой LLM-сценарий показан на демонстрации; детерминированный запуск
      не представлен как работа LLM.

## Передача организаторам

- [ ] Подготовлена запись или проведена репетиция по [DEMO.md](DEMO.md).
- [ ] Перед сдачей проверены итоговые `git diff`, staged diff и список файлов.
- [ ] Проверено отсутствие `.env`, API-ключей, токенов и credentials.
- [ ] Доступ к репозиторию соответствует правилам организаторов. В текущем Git
      уже находятся исходные CSV, погодный архив и модели; учитывайте это при
      изменении публичности или копировании в другой репозиторий.
- [ ] Итоговый commit и ссылка на репозиторий сверены после публикации.
- [ ] На платформе нажата **«Сдать решение»**, получено подтверждение.

Отдельный deployment не подтверждён. Детерминированный прогноз и ML-интеграция
проверены полностью по сценарию приёмки; LLM-запуск проверен для одного выпуска.
Полный replay через LLM и показ жюри остаются отдельными пунктами.
